## Módulo 1: Fundamentos y Control de Flujo Avanzado

1. [Entorno y Hola Mundo: Teoría de la JVM/Bytecode y armar el proyecto en Gradle con un banner de bienvenida.](../../course-2-beginners/01-environment-and-hello-world)
2. [Variables y Null Safety: Mutabilidad y un módulo de entrada seguro (cero caídas por nulos).](../../course-2-beginners/02-variables-and-null-safety)
3. Jerarquías y Control de Flujo: Expresiones if/when, enums, sealed classes y el bucle del menú (Esta ya la tengo en revisión de PR).
4. Anatomía de Funciones: Argumentos, sobrecargas y refactorización del chat a funciones limpias.

## Módulo 2: Pensamiento Funcional (FP)

5. Extensiones e Infix: Sintaxis fluida para colorear la terminal (ej. "Error".red()).
6. Higher-Order Functions: Funciones personalizadas como un myFilter para censurar palabras prohibidas.
7. Colecciones y Secuencias: Lazy vs Eager memory y armado del historial de mensajes.
8. Scope Functions (La navaja suiza): Cuándo usar let, run, apply, etc., para instanciar y mutar el perfil del usuario.

## Módulo 3: POO Avanzada y Tipado (El Choque con Java)

9. Clases y Visibilidad: Composición sobre herencia y encapsulación del ChatEngine.
10. Companion y Object Declarations: Singletons idiomáticos y modelado estricto de mensajes con sealed classes y data objects.
11. Genéricos Avanzados: Varianza (in/out) y un envoltorio Result\<T\> para las respuestas de la IA.
12. Delegación: Patrón Delegate para autoguardar el historial en un .txt cada que haya cambios.

## Módulo 4: Asincronía y Proyecto Final

13. Corrutinas vs Asincronía: Hilos vs suspensión y detección de bloqueos de I/O en consola.
14. Suspensión y Scopes: Animación concurrente de "Escribiendo..." en la terminal usando suspend.
15. Contextos y Dispatchers: Cambiar entre IO/Default/Main de forma segura para peticiones pesadas.
16. Proyecto Final (AI Chat CLI): Revisión de arquitectura, ciclo de vida y empaquetar todo en un JAR ejecutable listo para distribuir.
