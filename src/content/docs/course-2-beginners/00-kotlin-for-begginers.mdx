## ¿Por qué elegir Kotlin?

Kotlin fue diseñado por ingenieros de JetBrains para resolver los dolores de cabeza reales de los desarrolladores: eliminar el código repetitivo (*boilerplate*), erradicar las excepciones en tiempo de ejecución por referencias nulas y ofrecer interoperabilidad transparente con el ecosistema Java.

<CardGrid stagger>
  <Card title="⚡ Conciso y Productivo" icon="seti:kotlin">

  <Card title="🛡️ Seguro por Defecto (Null Safety)" icon="shield">

## La Elegancia de Kotlin en Código

Observa cómo Kotlin combina simplicidad declarativa con máxima seguridad en solo unas líneas:

```kotlin
// 1. Modelado inmutable con valores por defecto en una sola línea
data class Message(val author: String, val text: String, val isAi: Boolean = false)

fun main() {
    // 2. Colecciones de solo lectura con inferencia de tipos
    val history = listOf(
        Message(author = "Estudiante", text = "¿Por qué Kotlin es tan popular?"),
        Message(author = "AI Assistant", text = "¡Porque es seguro, expresivo y divertido!", isAi = true)
    )

    // 3. Programación funcional fluida y Template Strings
    history
        .filter { it.isAi }
        .forEach { println("🤖 [${it.author}]: ${it.text}") }
}
```

## Ruta de Aprendizaje y Temario

El curso está estructurado en **4 módulos formativos** con **16 lecciones prácticas**:

### Módulo 1: Fundamentos y Control de Flujo Avanzado
Comprende cómo se ejecuta el código en la JVM y domina el flujo de tu aplicación.

1. [L1: Entorno Agnóstico y Hola Mundo](../../course-2-beginners/01-environment-and-hello-world) <Badge text="Disponible" variant="success" />  
   *La JVM, Bytecode, compilador `kotlinc`, Gradle y banner inicial de bienvenida.*
2. [L2: Variables, Tipos y Null Safety](../../course-2-beginners/02-variables-and-null-safety) <Badge text="Disponible" variant="success" />  
   *Mutabilidad `val`/`var`, el error del billón de dólares, Platform Types y validación segura de entradas.*
3. [L3: Jerarquías y Control de Flujo Exhaustivo](../../course-2-beginners/03-hierarchies-and-control-flow) <Badge text="WIP" variant="caution" />  
   *Expresiones `if`/`when`, `enum`, `sealed classes/interfaces` y el bucle principal del menú.*
4. [L4: Anatomía de Funciones](../../course-2-beginners/04-anatomy-of-functions) <Badge text="WIP" variant="caution" />  
   *Named arguments, default parameters, single-expression functions y modularización del chat.*

### Módulo 2: Pensamiento Funcional (FP)
Aprende a pensar de forma declarativa y a construir interfaces fluidas.

5. [L5: Extensiones y Funciones Infix](../../course-2-beginners/05-extension-and-infix-functions) <Badge text="WIP" variant="caution" />  
   *Extension functions, extension properties, sintaxis `infix` y coloreado dinámico de la terminal.*
6. [L6: Funciones de Orden Superior y Lambdas](../../course-2-beginners/06-higher-order-functions) <Badge text="WIP" variant="caution" />  
   *Tipos de función, trailing lambdas, `inline functions` y pipeline de sanitización de mensajes.*
7. [L7: Colecciones y Secuencias (Lazy vs Eager)](../../course-2-beginners/07-collections-and-sequences) <Badge text="WIP" variant="caution" />  
   *List/Set/Map, operaciones funcionales (`map`, `filter`), evaluación perezosa con `Sequence` e historial.*
8. [L8: Funciones de Ámbito (Scope Functions)](../../course-2-beginners/08-scope-functions) <Badge text="WIP" variant="caution" />  
   *`let`, `run`, `with`, `apply` y `also`: la navaja suiza para inicializar y mutar perfiles de usuario.*

### Módulo 3: POO Avanzada y Tipado (El Choque con Java)
Diseña arquitecturas robustas, desacopladas y fuertemente tipadas.

9. [L9: Clases, Herencia y Visibilidad](../../course-2-beginners/09-classes-and-visibility) <Badge text="WIP" variant="caution" />  
   *Constructores, visibilidad, clases `open` vs `final` por defecto y encapsulación del `ChatEngine`.*
10. [L10: Companion Objects y Object Declarations](../../course-2-beginners/10-companion-and-object-declarations) <Badge text="WIP" variant="caution" />  
    *Singletons thread-safe, `companion object`, `data object` y modelado formal de eventos.*
11. [L11: Genéricos Avanzados y Varianza](../../course-2-beginners/11-advanced-generics) <Badge text="WIP" variant="caution" />  
    *Varianza (`in`/`out`), tipos reificados (`reified`) y envoltorio `Result<T>` para la IA.*
12. [L12: Delegación y Propiedades Delegadas](../../course-2-beginners/12-delegation) <Badge text="WIP" variant="caution" />  
    *Delegación nativa con `by`, `lazy`, `observable` y persistencia automática del historial en disco.*

### Módulo 4: Asincronía y Proyecto Final
Domina la concurrencia moderna y distribuye tu aplicación.

13. [L13: Corrutinas vs Asincronía Tradicional](../../course-2-beginners/13-coroutines-vs-asynchrony) <Badge text="WIP" variant="caution" />  
    *Hilos de la JVM vs Corrutinas ligeras, suspensión no bloqueante y benchmarks de I/O.*
14. [L14: Suspensión y Scopes de Concurrencia](../../course-2-beginners/14-suspension-and-scopes) <Badge text="WIP" variant="caution" />  
    *Funciones `suspend`, `CoroutineScope`, `launch`/`async` y animación concurrente de "IA escribiendo...".*
15. [L15: Contextos y Dispatchers](../../course-2-beginners/15-contexts-and-dispatchers) <Badge text="WIP" variant="caution" />  
    *`Dispatchers.IO` vs `Default`, `withContext` y llamadas concurrentes seguras a APIs.*
16. [L16: Proyecto Final: Empaquetado y Distribución](../../course-2-beginners/16-final-project-ai-chat) <Badge text="WIP" variant="caution" />  
    *Integración arquitectónica completa, JVM Shutdown Hooks, Fat JAR con Gradle y distribución multiplataforma.*
