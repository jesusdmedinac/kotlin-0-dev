## What will you learn in this lesson?

In this lesson we will explore:
- **Deep Theory:** Assembling the complete system architecture, console application lifecycle, JVM Shutdown Hooks for graceful exit, and packaging standalone executable binaries (`Shadow / Fat JAR`) with Gradle.
- **Under the Hood:** How Fat JAR packaging bundles all transitive dependencies (Kotlin Standard Library, Coroutines, etc.) into a single executable `.jar` file with a configured `MANIFEST.MF`.
- **Incremental Lab (AI Chat CLI):** Compiling, verifying end-to-end, and distributing your standalone, production-ready AI Assistant CLI tool.
