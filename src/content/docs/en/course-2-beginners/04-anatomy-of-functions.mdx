## What will you learn in this lesson?

In this lesson we will explore:
- **Deep Theory:** Default arguments, named arguments, single-expression functions, and variable-length arguments (`vararg`).
- **Under the Hood:** How the Kotlin compiler generates synthetic overloads and bitmask flags (`$default` methods) in JVM Bytecode for seamless Java interoperability.
- **Incremental Lab (AI Chat CLI):** Modularizing the chat application loop into clean, maintainable, and reusable functions.
