## What will you learn in this lesson?

In this lesson we will explore:
- **Deep Theory:** The 5 scope functions (`let`, `run`, `with`, `apply`, `also`), key differences between context objects (`this` vs `it`), and return values (the context object vs the lambda result).
- **Under the Hood:** How the Kotlin compiler inlines scope functions to eliminate runtime method-call penalties and object overhead.
- **Incremental Lab (AI Chat CLI):** Idiomatic initialization, fluent configuration, and profile state mutations for user sessions.
