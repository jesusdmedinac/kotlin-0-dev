## 1. Project Organization & Modules

A full Compose Multiplatform application generated by the Kotlin Multiplatform wizard or IntelliJ IDEA follows this modular layout:

```
ComposeDemo/
├── gradle/libs.versions.toml             # Central version catalog
├── shared/                               # Shared UI & Business Logic module
│   ├── build.gradle.kts
│   └── src/
│       └── commonMain/
│           ├── composeResources/         # Shared multiplatform assets (drawables, fonts, strings)
│           └── kotlin/
│               └── compose.project.demo/
│                   └── App.kt            # Core root Composable
├── androidApp/                           # Android native host application (MainActivity)
├── iosApp/                               # iOS native host application (Xcode project / ContentView)
├── desktopApp/                           # Desktop host application (JVM main())
└── webApp/                               # WebAssembly / JS browser host application
```

## 2. Shared Composable Root (`App.kt`)

File: `shared/src/commonMain/kotlin/compose/project/demo/App.kt`

```kotlin
package compose.project.demo

import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.safeContentPadding
import androidx.compose.material3.Button
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.Text
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.tooling.preview.Preview

@Composable
@Preview
fun App() {
    MaterialTheme {
        // Compose state tracking
        var timeAtLocation by remember { mutableStateOf("No location selected") }

        Column(
            // Fills all available space while adapting to system bars (status bar, notches)
            modifier = Modifier
                .safeContentPadding()
                .fillMaxSize(),
        ) {
            Text(timeAtLocation)
            Button(onClick = { timeAtLocation = "13:30" }) {
                Text("Show Time At Location")
            }
        }
    }
}
```

### Key Compose Mechanics Explained:
* **`remember { mutableStateOf(...) }`:** Allocates a state container in the Compose runtime. The value persists across recompositions.
* **Recomposition:** When `timeAtLocation` is mutated inside `onClick`, the Compose runtime invalidates and redraws only the composable nodes that read `timeAtLocation`.
* **`Modifier.safeContentPadding()`:** Automatically offsets content from device notches, dynamic islands, navigation bars, and desktop window borders across all target platforms.

## 3. Desktop Application Host & Hot Reload

File: `desktopApp/src/desktopMain/kotlin/main.kt`

```kotlin
package compose.project.demo

import androidx.compose.ui.unit.DpSize
import androidx.compose.ui.unit.dp
import androidx.compose.ui.window.Window
import androidx.compose.ui.window.WindowPosition
import androidx.compose.ui.window.application
import androidx.compose.ui.window.rememberWindowState

fun main() = application {
    // Sets initial size and position of the desktop window
    val state = rememberWindowState(
        size = DpSize(400.dp, 350.dp),
        position = WindowPosition(300.dp, 300.dp)
    )

    Window(
        title = "Local Time App",
        onCloseRequest = ::exitApplication,
        state = state,
        alwaysOnTop = true // Keeps window visible during live development
    ) {
        App()
    }
}
```

### Compose Hot Reload:
* Run the Gradle task: `desktopApp [hot] 🔥`.
* Any modifications saved in `App.kt` or desktop layout files are hot-swapped into the running desktop window within milliseconds without losing application runtime state.
