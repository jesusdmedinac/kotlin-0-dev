## 1. JetBrains Official Computer Science Curriculum

JetBrains provides a comprehensive toolkit for university-level and professional computer science instruction called **"Programming in Kotlin"**.

```
JetBrains Academic Curriculum Architecture
├── 1. Foundations & Language Mechanics
│   ├── 01. Introduction to Kotlin (Syntax, Null Safety, Types)
│   ├── 02. Object-Oriented Programming (Classes, Interfaces, Inheritance)
│   ├── 03. Generics (Variance, Reification, Constraints)
│   └── 04. Collections & Sequences (Lazy vs Eager, Functional operations)
│
├── 2. Advanced Paradigms & Systems
│   ├── 05. Functional Programming (Higher-Order Functions, Inline, Lambdas)
│   ├── 06. Parallel and Concurrent Programming (Threads, Synchronization)
│   ├── 07. Asynchronous Programming (Coroutines, Scopes, Channels, Flows)
│   └── 08. Exceptions & Error Handling
│
├── 3. Engineering Practices & Internals
│   ├── 09. Testing (JUnit 5, Kotest, MockK, Property-based testing)
│   ├── 10. Build Systems (Gradle Kotlin DSL, Multi-project builds)
│   ├── 11. JVM & Kotlin Compiler Internals (Bytecode, IR, Desugaring)
│   └── 12. Reflection on the JVM (Metadata, Type inspection, Annotations)
│
└── 4. Applied Tracks
    ├── Backend Development with Kotlin (Ktor, Spring Boot, Databases)
    ├── Test-Driven and Spec-Driven Development (TDD / BDD with Kotlin)
    └── Atomic Kotlin (Foundational hands-on labs by Bruce Eckel & Svetlana Isakova)
```

---

## 2. Assessment Resources & Evaluation Instruments

The curriculum includes standardized assessment materials:
* **Quizzes:** Conceptual checks validating understanding of memory models, nullability edge cases, and variance rules.
* **Homework Assignments:** Practical implementation projects testing idiomatic solution design.
* **Exams & Tests:** Comprehensive summative evaluation instruments.
